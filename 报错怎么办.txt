达妮卡桌宠 · 被拦截/报错时怎么办

这个程序是 PyInstaller 打包的，没有代码签名。部分杀毒软件（尤其 Windows Defender 的
机器学习启发式）会把它误判成木马，典型名字是 Trojan:Win32/Bearfoos.B!ml 或
Wacatac.B!ml —— 这类带有 "!ml" 后缀的都是启发式猜测，不是特征码命中。

下面按情况处理，做完通常就能正常启动。

────────────────────────────────
情况一：Windows Defender 报毒（最常见）
────────────────────────────────
1. 打开「Windows 安全中心」→「病毒和威胁防护」→「保护历史记录」
2. 找到这条威胁（Trojan:Win32/Bearfoos.B!ml），点开
3. 选择「允许在设备上」/「还原」
4. 再把解压目录加入排除项，避免下次又被删：
   「病毒和威胁防护」→「管理设置」→「排除项」→「添加或删除排除项」
   →「添加排除项」→「文件夹」→ 选中解压出来的 DanicaPet 文件夹

或者用管理员权限的 PowerShell 一行搞定（把路径换成实际解压位置）：
   Add-MpPreference -ExclusionPath "D:\你的路径\DanicaPet"

────────────────────────────────
情况二：提示「Windows 已保护你的电脑」（SmartScreen）
────────────────────────────────
1. 点弹窗里的「更多信息」
2. 点「仍要运行」
如果连「仍要运行」都没有：右键 exe →「属性」→ 底部勾选「解除锁定」→ 确定，再双击。

────────────────────────────────
情况三：解压后 DanicaPet.exe 不见了，或者只有 0 字节
────────────────────────────────
说明已经被杀软隔离。按「情况一」恢复并加排除项，然后重新解压一次压缩包。

────────────────────────────────
情况四：360 / 火绒 / 腾讯电脑管家 拦截
────────────────────────────────
在弹窗里选「添加信任」/「允许本次操作」，或把 DanicaPet 文件夹加入软件的信任区/白名单。
火绒：「病毒查杀」→「信任区」→ 添加目录。

────────────────────────────────
情况五：能启动，但桌面没出现快捷方式
────────────────────────────────
双击文件夹里的「安装快捷方式.cmd」，它会单独创建桌面快捷方式。
也可以右键宠物 →「重建桌面快捷方式」。

────────────────────────────────
其他说明
────────────────────────────────
- 程序不联网上传任何文件；联网只做三件事：查天气（中国天气网）、查新闻（60s API）、
  调 DeepSeek 对话接口。没有填 API Key 时，对话功能不可用，其余功能正常。
- 数据全部存在本机 %LOCALAPPDATA%\desktop-pet\。
- 如果实在不放心，可以只把 DanicaPet 文件夹放进沙箱/虚拟机里试运行，或放弃 exe，
  改用源码运行（需要 Python 3.11 + PySide6）。
